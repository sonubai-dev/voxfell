## Voxfell AI

Voxfell AI is an offline-first Android voice generation application designed to convert text scripts into natural speech directly on the device.

### ✨ Features

* 🎙️ Offline text-to-speech generation
* 👨‍🦱 Multiple male & female voice options
* 🎛️ Voice speed, pitch and volume controls
* 🎭 Tone presets for different speaking styles
* 🌐 Works without an API key or backend
* 📱 Optimized for Android devices
* 💾 Generate and save audio locally
* ▶️ Built-in audio playback
* 📤 Share generated audio files
* 📝 Script history and local storage
* 🔒 Privacy-focused — your scripts and generated audio stay on your device
* ⚡ Designed with low-resource and offline usage in mind

### 🏗️ Technology

Built with Kotlin and Jetpack Compose using a clean, modular Android architecture and the native Android Text-to-Speech engine.

### 🔮 Future Vision

Voxfell AI is designed with an extensible voice-engine architecture so future versions can support lightweight on-device neural TTS and true local voice-cloning models without requiring cloud APIs.
